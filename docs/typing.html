Typing reference

How codes, lists and paging work.

Codes and the list

Type a transliteration code. The matching words in hieroglyphs appear in a list. Press the number of your choice, or use the arrow keys and Return. Press , (comma) for the next page of the list; Page Up goes back.

The list learns: the signs you choose often for a code move up over time.

Keys with alternatives

Hyphens, question marks and case

Some codes contain - or ?, such as pt-m-Aiw. Type them exactly as they appear in the dictionary. Uppercase and lowercase codes are distinct: kA and ka may give different signs.
