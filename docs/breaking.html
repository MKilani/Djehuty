How the font works

Breaking characters

Keeping two signs apart when the font would join them.

The problem

The font applies ligatures in the direction of writing. If the pairs A–B and B–C both form ligatures, the sequence A–B–C always displays A–B, never B–C. Sometimes a ligature is also simply not wanted.

The solution

A breaking ligature character stops the font from joining two signs. It is invisible in the output. Djehuty uses the zero-width non-joiner (ZWNJ, U+200C), which is a joining control and does what is needed.

Earlier versions of the project's text recommended the zero-width space (ZWSP, U+200B). That character marks where a line may break and is not a joining control, so Djehuty does not use it.

Seeing the character

Breaking characters are invisible, but many editors show them with the formatting marks option switched on.

Where to use it

  • Only where needed. Use the character only to prevent specific wrong ligatures. This suits static texts such as articles and monographs.
  • Between every quadrat. Separate every pair of signs that should not join. This suits texts that will be edited or reused, such as corpora and databases, because the rendering then does not depend on which ligatures a later font version contains.

Search

Search functions treat breaking characters differently. Some ignore them, and others do not. Test the program you use before relying on a search.
