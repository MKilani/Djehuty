How Djehuty works: a short demonstration.

What it is

Djehuty is an input method for macOS. It takes the letters you type, shows a list of matching words or strings in hieroglyphs, and inserts the one you choose.

Any program

Works in any text field: editors, word processors, emails, browsers, databases and online forms.

Searchable

Hieroglyphs are characters. They can be searched, copied and sorted like any other text.

Exportable

The text can be exported, for example to PDF, and stays searchable.

Two parts

The EgyptianHiero font, which displays the signs, and Djehuty, which types them.

How it works

Type a code

For example kwi. Each word in the dictionary has one or more transliteration codes.

Choose a word or string

Press its number, or use the arrow keys and Return. The list learns: your usual choices rise to the top.

The font does the layout

Signs are grouped into quadrats automatically. There is no need for position markers or control characters.

Ligatures

The font joins signs that belong together, so you never have to say how to stack or combine them. You only say where to keep them apart: type 0 and choose the first entry in the list, an invisible breaking character. It stops the font from joining the signs on either side.

Breaking characters

Where two signs must stay apart, Djehuty inserts an invisible breaking character, the zero-width non-joiner (U+200C). It does not show in the text. Quadrats and ligatures and Breaking characters explain both.

How to get and install it

Download

Get Djehuty.pkg from the Releases page. macOS 12 or later, Intel and Apple silicon.

Install and log out

Run the installer, which also installs the EgyptianHiero font. Then log out and back in.

Add the input

System Settings, Keyboard, Text Input, Edit. Add Djehuty (Egyptian Hieroglyphs).

Deploy

Choose Deploy from the Djehuty menu bar icon. Repeat after each update.

If macOS blocks the installer

An unsigned installer may be reported as coming from an unidentified developer. Open System Settings, Privacy & Security, and choose Open Anyway. The user guide has the full instructions.
