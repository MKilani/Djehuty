# Website source

These files are the project website, served by GitHub Pages from this folder.

- Edit `build_site.py` to change the text, then run `python3 build_site.py` to regenerate the HTML pages.
- `style.css` holds the colours and layout for every page.
- Add `how-it-works.mp4` here (see VIDEO.txt) and the pictures in `../imagesReadme/`.
